# Wöchentliche Verbesserungen

Protokoll der Sonntags-Session „auf-stand: wöchentliche Verbesserung" (siehe UEBERGABE.md).
Je Woche höchstens **eine** kleine, belegte Änderung — neueste oben.

**Öffentliches Repo:** nur zusammengefasste Werte, keine Chat-IDs, keine State-Auszüge.

Format je Eintrag:

```
## KW <nn> (<Datum>) — <Kurztitel>
- Signale: <z. B. 6 Votes: Wirtschaft 4× Relevant, Politik 2× Weniger; 3 von 28 Ausgaben geöffnet>
- Anlass: <welcher Befund, warum diese eine Änderung>
- Änderung: <was, wo> · PR #<n> · gemergt ja/nein (Grund)
- Erwartung: <woran man nächste Woche sieht, ob es gewirkt hat>
```
